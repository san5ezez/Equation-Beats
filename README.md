## ✨ Что это

Идея пришла из коротких видео, где математическая функция рисуется точкой слева направо, и каждый её пик превращается в удар барабана.

Здесь так же, но уравнение вводишь **ты сам**. График рисуется в реальном времени, а звук считается прямо из формулы.

## 🚀 Быстрый старт

1. Скачай файл `beat.html`.
2. Открой его в любом современном браузере (Chrome, Safari, Firefox, Edge), в том числе на телефоне.
3. Нажми **▶ Играть**. Браузеры не разрешают звук без нажатия, поэтому это обязательно.
4. Меняй уравнение в поле `y =` и слушай результат.

Хостинг не нужен. Можно положить файл в репозиторий и включить **GitHub Pages**, тогда сайт будет доступен по ссылке.

## 🎛 Возможности

| Возможность | Описание |
|---|---|
| **Одно уравнение** | Одно поле `y = …`, график перерисовывается сразу при вводе |
| **Режим «бит»** | Каждый резкий скачок вверх даёт удар бочки. Чем больше скачок, тем сильнее удар |
| **Режим «тон»** | Высота звука следует за значением `y`, подходит для плавных функций |
| **Пресеты** | Готовые уравнения в один тап |
| **Ползунки** | Скорость, длина оси `x`, громкость |
| **Автомасштаб** | Ось `y` подстраивается под график |

## 🧮 Синтаксис

В уравнении доступна переменная **`x`** (время, секунды).

| Что | Как писать |
|---|---|
| Степень | `x^2` |
| Остаток от деления | `mod(x, 1)` (всегда положительный) |
| Число Эйлера | `e` |
| Экспонента | `e^(-3*x)` или `exp(-3*x)` |
| Число π | `PI` или `π` |
| Функции | `sin`, `cos`, `tan`, `abs`, `sqrt`, `floor`, `pow`, `min`, `max`, `log` |
| Дроби | `4/3` |

## 📚 Примеры

### 1. Бит из ролика

Две бочки с периодами 1 и 4/3. Каждые 4 секунды удары совпадают и звучат тяжелее остальных.

```
-3 + 3.2*e^(-10*mod(x,1)) + 3.2*e^(-10*mod(x,4/3))
```

Режим: **бит**

### 2. Один простой удар

Классический «бум» раз в секунду.

```
-1 + 2*e^(-15*mod(x,1))
```

Режим: **бит**

### 3. Полиритмия 1 : 1.5 : 2

Три независимых удара накладываются друг на друга.

```
-3 + 3*e^(-12*mod(x,1)) + 3*e^(-12*mod(x,1.5)) + 3*e^(-12*mod(x,2))
```

Режим: **бит**

### 4. Синусоида в колоколе

Синус, который «включается» гауссианой раз в период.

```
y(t) = exp(−σ·(t mod T − t₀)²) · sin(2π·f·t)
```

С числами σ = 40, T = 1, t₀ = 0.5, f = 6 это выглядит так:

```
e^(-40*(mod(x,1)-0.5)^2)*sin(2*PI*6*x)
```

Режим: **тон**. Получается ритмичное «пик-пик» с плавным нарастанием и затуханием.

### 5. Два синуса

Биения от двух близких частот.

```
sin(3*x) + 0.5*sin(7*x)
```

Режим: **тон**

## 🧠 Как это работает

- **График.** Функция считается в 1200 точках на отрезке `[0, xmax]`. Рисуется на `<canvas>` до текущей позиции точки.
- **Режим «бит».** На каждом кадре функция проверяется с шагом `0.002` между прошлой и текущей позицией. Если `y` выросла больше чем на 12% от диапазона, срабатывает удар. Сила удара зависит от размера скачка.
- **Звук бочки.** Синусоида с быстрым падением частоты (примерно 220 → 38 Гц) плюс короткий щелчок атаки. Всё синтезируется через Web Audio API, без аудиофайлов.
- **Режим «тон».** Один осциллятор, частота которого плавно следует за `y`.
- **Разбор формулы.** Строка превращается в функцию через `new Function`, а `^` заменяется на `**`. Запись вроде `3.2e^` понимается как `3.2*e^`.

## ⚠️ Замечания

- Формулы выполняются как JavaScript в твоём браузере. Не вставляй чужие уравнения из недоверенных источников.
- На iPhone включи звонковый режим, иначе Web Audio может молчать.
- Если график «обрезается», увеличь **Длину x**.
